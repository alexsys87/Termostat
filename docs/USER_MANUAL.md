# Термостат: инструкция пользователя

Цифровой термостат на STM32F030 с датчиками DS18B20, ЖКИ 8×2, реле и тремя кнопками.
Здесь описано, как им пользоваться: первое включение, типовые настройки, аварии и что делать при неполадках.
Полный список параметров с диапазонами — в разделе [«Работа с прибором»](../README.md#работа-с-прибором) README.

## 1. Подключение

1. Датчики DS18B20 подключаются по трём проводам (GND, DQ, +3.3 В) параллельно на одну линию, до 4 штук.
   Нужен подтягивающий резистор 4.7 кОм между DQ и +3.3 В (2.2–3.3 кОм для длинных линий).
   Паразитное питание не поддерживается.
2. Нагрузка (нагреватель, компрессор, насос) включается через контакты реле. Проверьте, что реле и проводка
   рассчитаны на ток нагрузки.
3. Подайте питание. Прибор коротко пискнет, через 1–2 с на экране появится температура.

## 2. Экран и кнопки

```
 22.5 C*     температура; * — реле (нагрузка) включено
25.0 OFF     уставка и состояние реле
```

| Кнопка    | На главном экране        | В меню                    | При редактировании значения |
|-----------|--------------------------|---------------------------|-----------------------------|
| UP / DOWN | уставка +0.5 / −0.5 °C   | выбор пункта              | изменить значение           |
| ENTER     | открыть меню             | войти / начать изменение  | закончить изменение         |

- Удержание UP/DOWN включает автоповтор, при долгом удержании шаг увеличивается в 10 и 100 раз.
- В меню выбранный пункт отмечен `>`. При редактировании в первой строке название, во второй значение.
- Пункт `Back` возвращает на уровень выше; из главного меню — на основной экран.
- Через 30 с без нажатий меню закрывается само (незавершённое «опасное» действие при этом не выполняется).
- Изменённые настройки сохраняются во Flash сами: при выходе из меню или через 10 с после последнего нажатия
  на главном экране. Питание можно выключать после этого.
- Через 10 мин без нажатий дисплей гаснет (настраивается, `Sys → TOut`); первое нажатие только включает его.

Структура меню:

```
Basic   Reg Setp Hyst Mode Relay Dly Cyc Units Manual   основные настройки
Alarm   Safe Min Max AHys Latch Sound                    аварийные пределы
PID     Kp Ki Kd P.Per Lim Tune                          ПИД-регулятор, автонастройка
Sensor  Src Found Scan Filt Res Upd                      датчики
Cal     Offs P1T P1M P2T P2M                             калибровка
Sys     Auto Save Beep Pwr TOut KeyR RptD RptR Deb Fact  система, сброс
Stats   T1..T4 TMin TMax Run Cycl Clr                    показания и статистика
```

Пример: изменить гистерезис. ENTER (меню) → `>Basic` → ENTER → DOWN до `>Hyst` → ENTER →
UP/DOWN до нужного значения → ENTER → DOWN до `>Back` → ENTER → `>Back` → ENTER (главный экран).

## 3. Первая настройка

1. **Проверьте датчики**: `Sensor → Found` — сколько датчиков найдено. Если меньше, чем подключено, проверьте
   проводку и выполните `Sensor → Scan`. Показания каждого датчика — `Stats → T1…T4`.
2. **Выберите режим**: `Basic → Mode` — `Heat` (нагрев) или `Cool` (охлаждение).
3. **Задайте уставку** кнопками UP/DOWN на главном экране или в `Basic → Setp`.
4. **Задайте гистерезис** `Basic → Hyst` (по умолчанию 1.0 °C).
5. **Проверьте аварийные пределы** `Alarm → Min / Max` (по умолчанию 0…40 °C): уставка должна лежать внутри них,
   иначе нагрузка будет выключаться по аварии.
6. При необходимости смените единицы (`Basic → Units`, C/F) и логику реле (`Basic → Relay`, см. ниже).

## 4. Как работает регулирование (ON/OFF, по умолчанию)

- **Нагрев**: реле включается, когда температура ниже `уставка − гистерезис`, и выключается при достижении уставки.
  Пример: уставка 25.0, гистерезис 1.0 — включение ниже 24.0, выключение на 25.0.
- **Охлаждение**: включается выше `уставка + гистерезис`, выключается при снижении до уставки.
- `Dly` — минимальная пауза между любыми двумя переключениями (по умолчанию 2 с), защищает от дребезга.
- `Cyc` — минимальное время простоя перед повторным включением (по умолчанию 3 мин), нужно для компрессоров
  холодильников и кондиционеров. Для нагревателя можно поставить 0.

## 5. Типовые случаи

**Холодильник / погреб (компрессор).** `Mode = Cool`, `Cyc` = 3–5 мин, `Hyst` = 1–2 °C. Регулятор — только ON/OFF.

**Инкубатор, сушка, точное поддержание.** `Reg = PID`, затем автонастройка (раздел 6). Во второй строке вместо
`ON/OFF` показывается мощность `PWR: 45%`; реле включается на часть периода `P.Per`.

**Несколько датчиков.** `Sensor → Src` выбирает температуру регулирования: `S1…S4` — конкретный датчик,
`Avg` — среднее, `Min`/`Max` — минимальная/максимальная. Датчики нумеруются по их серийным кодам, поэтому номера
не меняются после перезапуска; после замены датчика выполните `Scan`.

**Реле с нормально замкнутыми контактами** или инвертирующий ключ — `Basic → Relay = NC`.

**Ручное управление** (проверка нагрузки, сервис): `Basic → Manual` — `Man On` (всегда включено), `Man Off`
(всегда выключено), `Auto` — обычная работа. Ручной режим имеет приоритет над аварийными пределами и отказом
датчика — не оставляйте прибор в нём без присмотра.

## 6. Автонастройка ПИД

1. Установите уставку, `Basic → Manual = Auto`, аварий быть не должно.
2. `PID → Tune` → ENTER → `On` → ENTER. Меню закроется, на экране `TUNE 0/4`.
3. Прибор несколько раз включает и выключает нагрузку около уставки (±0.3 °C) и по колебаниям вычисляет
   `Kp`, `Ki`, `Kd`. По окончании включается ПИД и звучит длинный сигнал.
4. Прервать — `PID → Tune = Off`. Автонастройка также прерывается ручным режимом, аварией и через 8 часов.
   `TUNE ERR` — настройка не удалась, любое нажатие убирает сообщение.

Во время автонастройки защиты `Dly` и `Cyc` не действуют — для компрессоров подбирайте коэффициенты вручную.

## 7. Аварии и сигналы

| На экране  | Что случилось                                     | Что делает прибор         | Что делать |
|------------|---------------------------------------------------|---------------------------|------------|
| `Sens.Err` | нет температуры: датчик не найден или не отвечает | выключает нагрузку, пищит | проверить датчик и провода; после восстановления связи работа продолжится сама |
| `LIMIT!`   | температура вне `Alarm → Min…Max`                 | выключает нагрузку, пищит | устранить причину; авария снимается при возврате внутрь пределов с запасом `AHys` |
| `LIM ACK?` | авария прошла, включена защёлка `Latch`           | нагрузка остаётся выключенной | нажать любую кнопку |

- Звуковой сигнал аварии повторяется каждые 5 с (`Alarm → Sound`). Первое нажатие любой кнопки на главном экране
  только выключает звук, следующее работает как обычно.
- Аварийные пределы можно отключить (`Alarm → Safe = Off`), но отказ датчика выключает нагрузку всегда
  (кроме ручного режима).
- В режиме ON/OFF и в ручном режиме каждое переключение реле сопровождается коротким сигналом.

## 8. Калибровка

- Простая поправка: `Cal → Offs` (−10…+10 °C) прибавляется к показаниям.
- По двум точкам: поместите датчик в среду с известной температурой (например, тающий лёд 0 °C), запишите эталон
  в `P1T` и показание прибора в `P1M`; то же для второй точки (например, 100 °C) в `P2T`/`P2M`.
  Значения по умолчанию `0/0` и `100/100` означают «без коррекции».

## 9. Прочее

- **Сохранить вручную** — `Sys → Save` (нужно, если автосохранение `Sys → Auto` выключено).
- **Сброс к заводским настройкам** — `Sys → Fact` → ENTER → `Yes` → ENTER (длинный сигнал).
- **Статистика**: `Stats → TMin/TMax` — минимум и максимум за сутки работы, `Run` — время работы нагрузки (мин),
  `Cycl` — число включений реле, `Clr → Yes` — обнулить.
- **Звук кнопок** — `Sys → Beep`; аварийный сигнал от него не зависит.
- `Sys → Pwr` — энергосбережение, `KeyR/RptD/RptR` — автоповтор кнопок, `Deb` — антидребезг.

## 10. Неполадки

| Проблема                                   | Возможная причина и решение |
|--------------------------------------------|-----------------------------|
| На экране ` --.-` сразу после включения    | первое измерение ещё идёт (1–2 с) |
| `Sens.Err`                                 | нет резистора 4.7 кОм, перепутаны провода, обрыв; проверьте `Sensor → Found`, затем `Scan` |
| Температура «прыгает»                      | увеличьте фильтр (`Sensor → Filt`, 1 — сильный, 0 и 10 — выключен), проверьте экранирование длинной линии |
| Реле не включается, хотя холодно           | действует пауза `Cyc` или `Dly`; включён `Man Off`; авария `LIMIT!`/`LIM ACK?`; уставка ниже температуры в режиме `Heat` |
| Нагрузка включена, но реле не щёлкает     | проверьте `Basic → Relay` (NO/NC) и ключ реле |
| Экран пустой                               | дисплей погашен по `TOut` — нажмите любую кнопку; иначе отрегулируйте контраст |
| Настройки не сохраняются после выключения  | выключите питание не раньше чем через 10 с после последнего нажатия или выйдите из меню; проверьте `Sys → Auto` |
